# The One-Line Laugh

Entry for the make.fun bounty
[The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)
— see [make.fun](https://make.fun) for more bounties.

## Entry

> I folded my laundry, put it on the chair, and now it lives there rent-free like a tiny roommate who never does the dishes.

(122 characters, one sentence.)

## How to run

```bash
python3 main.py
```

Writes the entry to `/output/entry.txt` and prints the character count.
Pure Python 3.13 standard library, deterministic — no network, no clock,
no randomness. For local testing, set `OUTPUT_DIR` to redirect the output:

```bash
OUTPUT_DIR=/tmp/laugh-test python3 main.py
```
